# Google Sheets → GO TOURNAMENT

ตัวเชื่อมนี้อ่านเฉพาะแท็บ `นำเข้าประวัติแมตช์` แล้วส่งข้อมูลไปตรวจที่ Next.js API ก่อนเก็บใน Supabase staging จึงไม่ทำให้หน้าเว็บอ่าน Google Sheets โดยตรง

## ติดตั้งในชีตกลาง

1. เปิด **Extensions → Apps Script** ในไฟล์ `1go Master / Platform Database`
2. วางเนื้อหา `Code.gs` แล้วบันทึก
3. เปิด **Project Settings → Script Properties** และเพิ่ม:
   - `GO_IMPORT_ENDPOINT` = `https://<โดเมนเว็บ>/api/imports/matches`
   - `GO_IMPORT_SECRET` = ค่าลับเดียวกับที่ตั้งใน Vercel
4. รีเฟรชชีต จะพบเมนู **GO TOURNAMENT**
5. กด **ตรวจข้อมูล (ไม่บันทึก)** ก่อนทุกครั้ง
6. เมื่อผ่านแล้วกด **ส่งเข้าตารางพัก**

## หลักป้องกันความผิดพลาด

- แถวที่ไม่มีรหัสแมตช์, GO ID, รุ่น, รอบ หรือผลคู่แข่งที่สัมพันธ์กันจะถูกปฏิเสธทั้งชุด
- รหัสแมตช์ซ้ำไม่สร้างข้อมูลซ้ำ เพราะใช้ `source_key` แบบ unique
- ต้องทำเครื่องหมาย `ตรวจสอบแล้ว` ทุกแถว
- การส่งเข้าตารางพัก **ยังไม่แสดงบนหน้าเว็บ** ต้องมีขั้นอนุมัติ/Publish แยกต่างหาก
- คีย์ Supabase และ shared secret อยู่ฝั่งเซิร์ฟเวอร์/Script Properties เท่านั้น ห้ามใส่ในเซลล์หรือโค้ดสาธารณะ

## ขอบเขตคะแนน

ตัวเชื่อมรอบนี้ไม่คำนวณคะแนนจากแท็บ `ELO RULESET` เพราะกติกาในแท็บยังเป็นฉบับเก่า ข้อสรุปปัจจุบันคือคะแนนเฉพาะระดับคิว: Beginner 100, 15K 160, เพิ่มระดับละ 60, 1K 1000 และไม่รวมระดับดั้ง
