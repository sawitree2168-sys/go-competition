# GO TOURNAMENT light mode design policy

Approved by ครูเล็ก on 29 October 2026.

- Use dark navy (#092956 or #092859) for card outlines, dividers, input borders and ordinary text. Do not use pale gray outlines or gray text.
- Use white card interiors and white or pale blue input backgrounds. Placeholder text stays dark navy.
- Use white text on navy filled controls; use dark navy text on white and gold controls.
- Keep the gold brand accents and meaningful status colors.
- Scope this policy to light mode; preserve dark-mode tokens.
- Apply the shared tokens to homepage, event and division details, registration, payment, profile and my-competition screens.
